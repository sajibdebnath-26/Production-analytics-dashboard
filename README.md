# Production Analytics Dashboard

Power BI dashboard for analyzing production performance and product quality.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query

## Dashboard Features

- Total Production
- Average Production
- Average Impurity
- Production by Product
- Impurity by Product
- Production & Quality Analysis
- Product-level filtering

## Project Files

- `Production_Dashboard.pbix` — Power BI dashboard
- `Production_Data.xlsx` — Practice production dataset
- `Dashboard_Screenshot.png` — Dashboard preview

## Purpose

This is a practice data analytics project created to demonstrate production data analysis and Power BI dashboard development.
